# Ahsanul Haque — Portfolio

A responsive, bilingual (English/Bangla) portfolio built with plain HTML, CSS, and JavaScript. No package installation or build step is needed.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static web server. For example, run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Deploy

Upload this folder to a static host such as GitHub Pages, Netlify, or Vercel. No build command is required; set the publish directory to this project root.

## Personalize

- Replace `assets/portrait.jpg` with an updated portrait, keeping the filename or changing its path in `index.html`.
- Edit bilingual page copy in `index.html`. Text with `data-en` and `data-bn` switches with the language control.
- Update metadata and replace the domain placeholders in `robots.txt` and `sitemap.xml` before deployment.
- Project cards are concept examples labeled as placeholders. Replace them with verified project details.
- Add confirmed education, experience, publications, certifications, and contact details when ready. Unverified credentials and social profiles are omitted.

## Contact form

The form validates fields in the browser but does not send messages. Connect a form provider or backend before publishing it as a working contact channel.
